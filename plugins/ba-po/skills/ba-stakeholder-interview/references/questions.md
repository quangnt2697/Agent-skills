# Bộ Câu hỏi Phỏng vấn Stakeholder (ba-stakeholder-interview)

## 1. Generic Questions (Cho tất cả stakeholders, 10-15 phút)

1. **Context:**
   - Vai trò của bạn trong tổ chức là gì?
   - Bạn tương tác với [feature/project này] như thế nào?
2. **Current State (AS-IS):**
   - Hiện tại bạn làm [task X] như thế nào?
   - Pain points lớn nhất của quy trình hiện tại là gì?
   - Có workarounds nào bạn đang dùng không?
3. **Future State (TO-BE):**
   - Bạn mong đợi [feature/project mới] sẽ giải quyết vấn đề gì?
   - Success criteria từ góc nhìn của bạn là gì?
4. **Constraints:**
   - Có limitations nào (budget, timeline, compliance) ảnh hưởng đến project này không?
   - Có risks nào bạn lo ngại không?
5. **Priority:**
   - Nếu chỉ làm được 50% scope, 50% nào bạn muốn ưu tiên?

## 2. Role-Specific Questions

### For CEO/Executive (Business Strategy)
1. **Strategic Alignment:** Project fit vào company strategy như thế nào? KPIs measure success?
2. **Competitive Landscape:** Competitors đang làm gì? Cần bắt kịp hay vượt qua họ?
3. **Investment:** Budget cap? Timeline expectation?
4. **Trade-offs:** Time-to-market vs Feature completeness? Mobile app vs Desktop app?

### For Product Manager (Features & Roadmap)
1. **User Personas:** Target users là ai? Top 3 user needs?
2. **Feature Priority:** Must-have features cho MVP? Nice-to-have features?
3. **Roadmap:** Release plan (1.0, 1.1, 2.0)? Dependencies?
4. **Metrics:** Làm sao measure adoption? Target numbers?

### For End User / Trader (Real Workflows)
1. **Current Workflow:** Mô tả chi tiết quy trình hiện tại. Mất bao lâu?
2. **Pain Points:** Điểm khó chịu nhất? Bao nhiêu lần bị lỗi/miss trade?
3. **Ideal Solution:** 3 tính năng quan trọng nhất?
4. **Edge Cases:** Tình huống đặc biệt (peak hours, thị trường sập)? Cách xử lý?

### For Support Team (Common Issues)
1. **Top Issues:** Top complaints? Issues recurring?
2. **Workarounds:** Hướng dẫn customers làm gì khi gặp issue? Có "unofficial" workarounds?
3. **Feature Requests:** Customers yêu cầu gì nhiều nhất?
4. **Training:** App mới có dễ dùng không? Documentation cần gì?

### For CTO/Tech Lead (Technical Constraints)
1. **Tech Stack:** Limitations hiện tại? Legacy systems cần integrate?
2. **Scalability:** Expected load? Infrastructure ready?
3. **Security & Compliance:** Security requirements? Audit trails?
4. **Integration:** External systems? APIs available?

### For Compliance Officer (Regulatory)
1. **Regulatory Requirements:** HOSE/HNX rules? SBV/SSC regulations?
2. **Audit Trails:** Logs nào cần lưu? Retention period?
3. **Risk Management:** Red flags cần block? Alerts cần config?
4. **Approval Process:** Feature mới cần approval từ ai? Timeline?
